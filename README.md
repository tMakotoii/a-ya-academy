# Каталог одежды

Мини-каталог на React с поиском, фильтром наличия, карточками товаров и корзиной. [Условие тестового задания](TASK.md).

## Запуск

Понадобятся Node.js и npm. Проверено на Node.js 24 и npm 12.

```bash
git clone https://github.com/tMakotoii/a-ya-academy.git
cd a-ya-academy
npm ci
npm start
```

Откройте [http://localhost:3000](http://localhost:3000).

## Что проверить

1. В каталоге найдите товар по названию или отсортируйте товары по цене.
2. Откройте карточку, выберите цвет и размер и добавьте товар в корзину. Выбранные цвет и размер можно открыть по тому же URL.
3. В корзине измените количество и обновите страницу. Позиции сохранятся. Промокод `SALE10` даёт скидку 10%.

## Тесты и сборка

```bash
npm test -- --watchAll=false
npm run build
```

Готовая сборка появится в папке `build/`.
